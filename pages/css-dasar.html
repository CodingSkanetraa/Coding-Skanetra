Kenalan dengan CSS

Atur warna, jarak, dan tata letak supaya halaman HTML-mu terlihat rapi dan menarik.

Pemula · 15 menit

1. Apa itu CSS?

CSS (Cascading Style Sheets) dipakai untuk mengatur tampilan halaman web: warna, ukuran huruf, jarak, sampai tata letak. HTML menyusun isi halaman, CSS yang mempercantiknya.

Satu aturan CSS terdiri dari selektor (elemen mana yang diatur) dan deklarasi (apa yang diubah) di dalam kurung kurawal. 

h1 {
  color: green;
  font-size: 32px;
}

Pada contoh di atas, h1 adalah selektor, color dan font-size adalah properti, sedangkan green dan 32px adalah nilainya.

2. Selektor: memilih elemen

Ada tiga selektor yang paling sering dipakai:

SelektorContohMemilih
Elemenp { }Semua elemen <p>.
Class.kartu { }Elemen dengan class="kartu".
ID#judul { }Elemen dengan id="judul". ID harus unik.
 
<p class="kartu">Halo!</p>

.kartu {
  background: #e8f5ee;
  padding: 16px;
}

Warna bisa ditulis dengan nama (red), kode heksadesimal (#18864b), atau rgb(24, 134, 75).

4. Box model: jarak dan ruang

Setiap elemen HTML adalah sebuah kotak. Dari dalam ke luar, kotak itu terdiri dari content, padding (jarak isi ke tepi), border (garis tepi), dan margin (jarak ke elemen lain). 

.kartu {
  padding: 20px;
  border: 2px solid #18864b;
  border-radius: 12px;
  margin: 16px auto;
  max-width: 400px;
}
  • padding mengatur ruang di dalam border.
  • margin mengatur ruang di luar border.
  • border-radius membuat sudut kotak jadi melengkung.

5. Layout dengan Flexbox

Flexbox memudahkan menata elemen dalam satu baris atau kolom. Cukup beri display: flex pada elemen induk. 

.menu {
  display: flex;
  gap: 12px;
  justify-content: center;
  align-items: center;
}
  • gap mengatur jarak antar anak elemen.
  • justify-content mengatur posisi sepanjang sumbu utama (mendatar secara bawaan).
  • align-items mengatur posisi pada sumbu silang (menurun secara bawaan).
