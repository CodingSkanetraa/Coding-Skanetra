1. Apa itu C++?

C++ adalah bahasa pemrograman yang cepat dan kuat. Ia dipakai untuk game, aplikasi desktop, sistem tertanam, dan lomba pemrograman seperti OSN Informatika. Beda dengan Python, kode C++ harus dikompilasi dulu menjadi program sebelum bisa dijalankan.

Program C++ paling sederhana: 

#include <iostream>
using namespace std;

int main() {
    cout << "Halo, CodingSkanetra!" << endl;
    return 0;
}
  • #include <iostream> memanggil pustaka untuk input dan output.
  • main() adalah tempat program mulai berjalan.
  • cout menampilkan teks ke layar, dan endl pindah ke baris baru.
  • Setiap perintah diakhiri tanda titik koma ;. Isi blok ditulis di dalam kurung kurawal { }.

2. Variabel dan tipe data

Di C++, tipe variabel harus ditulis saat membuatnya, lalu tipe itu tidak bisa berubah. 

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nama = "Kaito";   // teks
    int umur = 17;           // bilangan bulat
    double tinggi = 1.65;    // bilangan desimal
    char kelas = 'A';        // satu huruf
    bool aktif = true;       // benar/salah

    cout << nama << " " << umur << " " << tinggi << " " << kelas << " " << aktif << endl;
    return 0;
}
TipeContohKeterangan
int42Bilangan bulat
double3.14Bilangan desimal
char'A'Satu karakter, pakai tanda kutip tunggal
string"Halo"Teks, pakai tanda kutip ganda dan #include <string>
booltrue, falseBenar atau salah (ditampilkan sebagai 1 atau 0)

3. Input dan output

cin membaca masukan dari pengguna. Pakai >> untuk membaca satu kata atau angka, dan getline(cin, variabel) untuk membaca satu baris penuh (misalnya nama dengan spasi). 

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nama;
    int angka;

    cout << "Siapa namamu? ";
    getline(cin, nama);
    cout << "Halo, " << nama << "!" << endl;

    cout << "Masukkan angka: ";
    cin >> angka;
    cout << "Dua kali lipatnya: " << angka * 2 << endl;
    return 0;
}

Catatan: di Editor C++ pada web ini, isi semua masukan di kotak Input sebelum menekan Kompilasi & Jalankan, satu jawaban per baris.

4. Kondisi

Syarat ditulis di dalam tanda kurung ( ), dan isi blok di dalam { }. Untuk memilih dari banyak nilai tetap, pakai switch. Jangan lupa break di setiap case. 

#include <iostream>
using namespace std;

int main() {
    int nilai = 82;

    if (nilai >= 90) {
        cout << "Sangat baik" << endl;
    } else if (nilai >= 75) {
        cout << "Lulus" << endl;
    } else {
        cout << "Belum lulus" << endl;
    }

    int hari = 3;
    switch (hari) {
        case 1: cout << "Senin" << endl; break;
        case 2: cout << "Selasa" << endl; break;
        case 3: cout << "Rabu" << endl; break;
        default: cout << "Hari lain" << endl;
    }
    return 0;
}

Operator pembanding yang sering dipakai: == (sama dengan), != (tidak sama), <, >, <=, >=. Gabungkan syarat dengan && (dan) serta || (atau). Hati-hati: = untuk mengisi nilai, == untuk membandingkan.

5. Perulangan

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        cout << "Perulangan ke-" << i << endl;
    }

    int n = 3;
    while (n > 0) {
        cout << n << "..." << endl;
        n--;
    }
    cout << "Mulai!" << endl;
    return 0;
}

for cocok bila jumlah putarannya sudah jelas. Bagian dalam kurungnya ada tiga: nilai awal, syarat lanjut, dan langkah tiap putaran. while cocok bila berhenti berdasarkan suatu syarat. i++ artinya tambah satu, n-- artinya kurangi satu.

6. Fungsi

Fungsi menulis tipe hasil di depan namanya. Gunakan void bila fungsi tidak mengembalikan apa pun. Fungsi harus ditulis sebelum main() agar dikenali. 

#include <iostream>
#include <string>
using namespace std;

string sapa(string nama) {
    return "Halo, " + nama + "!";
}

int kuadrat(int x) {
    return x * x;
}

int main() {
    cout << sapa("Kaito") << endl;
    cout << sapa("Skanetra") << endl;
    cout << "7 kuadrat = " << kuadrat(7) << endl;
    return 0;
}

7. Array dan vector

Array menyimpan sejumlah nilai bertipe sama dengan ukuran tetap. Nomor urutnya (indeks) dimulai dari 0. Vector mirip array tetapi ukurannya bisa bertambah. 

#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int nilai[3] = {80, 90, 75};
    int total = 0;
    for (int i = 0; i < 3; i++) {
        total += nilai[i];
    }
    cout << "Rata-rata: " << total / 3.0 << endl;

    vector<string> buah = {"apel", "jeruk"};
    buah.push_back("mangga");
    for (string b : buah) {
        cout << b << endl;
    }
    cout << "Jumlah buah: " << buah.size() << endl;
    return 0;
}

Pembagian dua int di C++ menghasilkan bilangan bulat (7 / 2 hasilnya 3). Itu sebabnya contoh di atas membagi dengan 3.0 supaya hasilnya desimal.
