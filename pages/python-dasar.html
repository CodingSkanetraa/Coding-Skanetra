1. Apa itu Python?

Python adalah bahasa pemrograman serbaguna yang dipakai untuk web, analisis data, otomasi, hingga kecerdasan buatan. Sintaksnya mirip bahasa sehari-hari sehingga ramah untuk pemula.

Program Python pertama biasanya hanya satu baris: 

print("Halo, CodingSkanetra!")

Fungsi print() menampilkan teks atau nilai ke layar.

2. Variabel dan tipe data

Di Python, variabel dibuat cukup dengan memberi nama dan nilai. Tidak perlu kata kunci khusus. 

nama = "Kaito"      # str  (teks)
umur = 17           # int  (bilangan bulat)
tinggi = 1.65       # float (bilangan desimal)
aktif = True        # bool (benar/salah)

print(nama, umur, tinggi, aktif)
TipeContoh
str"Halo"
int42
float3.14
boolTrue, False
list["apel", "jeruk"]

3. Input dan output

input() membaca teks dari pengguna. Hasilnya selalu berupa str, jadi ubah dengan int() jika ingin dihitung. 

nama = input("Siapa namamu? ")
print("Halo,", nama)

angka = int(input("Masukkan angka: "))
print("Dua kali lipatnya:", angka * 2)

Catatan: di Editor Python pada web ini, input() muncul sebagai kotak dialog browser.

4. Kondisi

Python memakai indentasi (spasi di awal baris) untuk menandai isi blok kode. Jangan lupa tanda titik dua : setelah kondisi. 

nilai = 82

if nilai >= 90:
    print("Sangat baik")
elif nilai >= 75:
    print("Lulus")
else:
    print("Belum lulus")

5. Perulangan

for i in range(1, 4):
    print("Perulangan ke-", i)

buah = ["apel", "jeruk", "mangga"]
for item in buah:
    print(item)

range(1, 4) menghasilkan angka 1, 2, dan 3. Angka batas akhir (4) tidak ikut.

6. Fungsi

Fungsi dibuat dengan def. Gunakan return untuk mengembalikan hasil. 

def sapa(nama):
    return "Halo, " + nama + "!"

print(sapa("Kaito"))
print(sapa("Skanetra"))
