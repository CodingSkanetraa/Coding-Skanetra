1. Sebelum mulai

Proyek mini adalah program kecil yang menggabungkan beberapa hal sekaligus. Tiga proyek di bawah memakai Python dan bisa langsung dijalankan di Editor Python (mode Console). Cara mengerjakannya:

  1. Baca dulu tujuan proyeknya.
  2. Ketik kodenya sendiri di editor, jangan hanya salin. Mengetik membuat kamu lebih cepat paham.
  3. Jalankan, lalu ubah-ubah angka atau teksnya dan lihat apa yang terjadi.
  4. Kerjakan tantangan di akhir tiap proyek.

Prasyarat: sudah membaca materi Python Dasar.

2. Proyek 1: Kalkulator Mini

Tujuan: program yang meminta dua angka dan satu operasi, lalu menampilkan hasilnya. Kamu berlatih input(), float(), dan if / elif / else. 

print("=== Kalkulator Mini ===")
a = float(input("Angka pertama: "))
op = input("Operasi (+, -, *, /): ")
b = float(input("Angka kedua: "))

if op == "+":
    hasil = a + b
elif op == "-":
    hasil = a - b
elif op == "*":
    hasil = a * b
elif op == "/":
    if b == 0:
        hasil = "tidak bisa dibagi nol"
    else:
        hasil = a / b
else:
    hasil = "operasi tidak dikenal"

print("Hasil:", hasil)

Perhatikan bagian pembagian: sebelum membagi, program mengecek apakah pembaginya nol. Membagi dengan nol akan menyebabkan error, jadi dicegah lebih dulu.

Tantangan: tambahkan operasi ** (pangkat) dan % (sisa bagi).

3. Proyek 2: Tebak Angka

Tujuan: komputer memilih angka rahasia, pemain menebak sampai benar. Kamu berlatih import random, perulangan while, dan variabel penghitung. 

import random

rahasia = random.randint(1, 20)
tebakan = 0
percobaan = 0

print("Aku memilih angka antara 1 sampai 20. Coba tebak!")

while tebakan != rahasia:
    tebakan = int(input("Tebakanmu: "))
    percobaan += 1

    if tebakan < rahasia:
        print("Terlalu kecil")
    elif tebakan > rahasia:
        print("Terlalu besar")

print("Benar! Kamu berhasil dalam", percobaan, "percobaan.")

random.randint(1, 20) memilih satu angka acak dari 1 sampai 20, dan batasnya ikut terhitung. Perulangan while terus berjalan selama tebakan masih berbeda dari angka rahasia, sedangkan percobaan += 1 menghitung jumlah tebakan.

Tantangan: batasi pemain hanya 5 kesempatan. Jika habis, tampilkan angka rahasianya.

4. Proyek 3: Buku Nilai

Tujuan: menyimpan beberapa nilai ke dalam list, lalu menghitung nilai tertinggi, terendah, dan rata-ratanya. Kamu berlatih list, for, dan fungsi bawaan sum(), max(), min(), len(). 

nilai = []

jumlah = int(input("Berapa nilai yang mau dimasukkan? "))
for i in range(jumlah):
    n = int(input("Nilai ke-" + str(i + 1) + ": "))
    nilai.append(n)

rata = sum(nilai) / len(nilai)
print("Tertinggi:", max(nilai))
print("Terendah:", min(nilai))
print("Rata-rata:", round(rata, 1))

if rata >= 75:
    print("Kerja bagus, lulus!")
else:
    print("Ayo belajar lagi.")

nilai.append(n) menambahkan satu nilai ke akhir list. round(rata, 1) membulatkan hasil sampai satu angka di belakang koma.

Tantangan: minta juga nama tiap siswa, lalu tampilkan siapa yang nilainya tertinggi.

5. Tantangan lanjutan
