1. Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang berjalan di browser. Jika HTML adalah kerangka dan CSS adalah tampilan, JavaScript adalah yang membuat halaman bisa bereaksi: tombol yang bisa diklik, formulir yang divalidasi, dan sebagainya.

Cara paling mudah untuk menampilkan hasil adalah console.log(): 

console.log("Halo, CodingSkanetra!");

2. Variabel dan tipe data

Variabel adalah wadah untuk menyimpan nilai. Gunakan let untuk nilai yang bisa berubah dan const untuk nilai yang tetap. 

const nama = "Kaito";   // teks (string)
let umur = 17;          // angka (number)
let aktif = true;       // benar/salah (boolean)

umur = 18;              // boleh, karena let
console.log(nama, umur, aktif);
TipeContoh
String"Halo"
Number42, 3.14
Booleantrue, false
Array["apel", "jeruk"]

3. Kondisi: mengambil keputusan

Gunakan if, else if, dan else untuk menjalankan kode berdasarkan kondisi. 

const nilai = 82;

if (nilai >= 90) {
  console.log("Sangat baik");
} else if (nilai >= 75) {
  console.log("Lulus");
} else {
  console.log("Belum lulus");
}

Operator perbandingan yang sering dipakai: >, <, >=, <=, === (sama persis), dan !== (tidak sama).

4. Perulangan

Perulangan menjalankan kode yang sama berkali-kali. 

for (let i = 1; i <= 3; i++) {
  console.log("Perulangan ke-" + i);
}

const buah = ["apel", "jeruk", "mangga"];
for (const item of buah) {
  console.log(item);
}

5. Fungsi

Fungsi mengelompokkan kode agar bisa dipakai ulang. 

function sapa(nama) {
  return "Halo, " + nama + "!";
}

console.log(sapa("Kaito"));
console.log(sapa("Skanetra"));

6. Interaksi dengan halaman (DOM)

DOM adalah representasi halaman HTML yang bisa diubah lewat JavaScript. Contoh berikut mengubah teks saat tombol diklik: 

<button id="tombol">Klik aku</button>
<p id="pesan"></p>

<script>
  const tombol = document.querySelector("#tombol");
  const pesan = document.querySelector("#pesan");

  tombol.addEventListener("click", () => {
    pesan.textContent = "Halo dari JavaScript!";
  });
</script>

Kamu bisa mencoba kode non-DOM di Editor JavaScript pada menu Playground.
