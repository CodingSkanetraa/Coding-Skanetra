Pemula · 10 menit

1. Apa itu HTML?

HTML adalah singkatan dari HyperText Markup Language. HTML digunakan untuk menyusun struktur dan konten halaman web.

Bayangkan sebuah website sebagai rumah: HTML menyusun bagian-bagiannya, CSS mengatur tampilannya, sedangkan JavaScript menambahkan interaksi.

2. Struktur Dokumen HTML

Setiap dokumen HTML umumnya memiliki struktur seperti ini:

<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <title>Website Pertamaku</title>
  </head>
  <body>
    <h1>Halo, dunia!</h1>
    <p>Ini website pertamaku.</p>
  </body>
</html>
  • <!DOCTYPE html> menyatakan dokumen menggunakan HTML modern.
  • <html> menjadi elemen utama dokumen.
  • <head> memuat informasi tentang halaman.
  • <body> memuat konten yang tampil di halaman.

3. Elemen HTML Dasar

Elemen Fungsi
<h1> Judul utama halaman atau bagian.
<p> Paragraf teks.
<a> Tautan menuju halaman atau lokasi lain.
<img> Menampilkan gambar.
<ul> dan <li> Membuat daftar berpoin.
