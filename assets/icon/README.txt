IKON LOKAL CODINGSKANETRA
=========================
Taruh gambarmu di folder ini dengan NAMA FILE persis seperti di bawah.
Format: .png (disarankan, latar transparan) atau .svg/.webp. Ukuran: persegi, 128x128 px atau lebih (maksimal 512 px).
Bila file belum ada, situs otomatis memakai ikon garis bawaan, jadi tidak ada yang rusak.

Beranda HP (menu dan editor) dan halaman Playground:
  html.png  python.png  cpp.png            (juga dipakai di Materi)
  materi.png  playground.png  peringkat.png  games.png
  dokumentasi.png  struktur.png  profil.png

Halaman Materi:
  html.png  css.png  javascript.png  python.png  cpp.png  proyek-mini.png

Setelah menambah file, muat ulang halaman (kalau tidak berubah, hapus cache atau tambah ?v= di js/ikon-lokal.js).
